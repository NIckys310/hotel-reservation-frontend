# Hotel Reservation System – Frontend

React + Vite client for the hotel reservation workshop (Facade pattern). The code is in English and the user interface is in Spanish.

## Features

- Room search by dates and type, with availability for every room.
- Room selection with a dynamic price preview (high/low season and optional extra services).
- Reservation form with guest details.
- Reservation management panel: add services, view summary, check-in and check-out.
- Final invoice generated by the server.

## Run locally

```bash
cp .env.example .env   # point VITE_API_URL to the backend
npm install
npm run dev
```

## Deploy (Vercel)

Import the repository in Vercel (framework preset **Vite**) and set the environment variable
`VITE_API_URL` to the public backend URL (for example `https://hotel-reservation-backend.up.railway.app`).
